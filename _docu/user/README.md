---

Screenshots in `screenshots/` are generated by a harness that drives a running platform rather than
being taken by hand;
`client-` and `installation-` files are regenerated on every run, `manual-` files are
kept by hand because no script can reach the state they show.

Preparing a platform from empty spans several modules, so it is documented once for the whole
platform — in the user guide of the deployment repository — rather than here.
